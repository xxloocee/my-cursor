# MyCursor v1.0.2

## 修复

- 修复部分旧版本更新后因数据库历史迁移校验失败而无法启动的问题，保留已有配置。
- 停止写入模拟 Cursor 账号，透传 Cursor 官方账号接口的真实响应和认证错误。
- 修复模型上下文、推理强度、输出上限和 Anthropic thinking 预算未按已保存配置生效的问题；禁用的插件模型不再参与调用。
- 修复工具参数中的整数经协议转换后变成小数，导致兼容 API 返回 HTTP 400 的问题。
- 修复较大首条请求上传期间，提前到达的控制消息被错误拒绝，导致 Cursor 会话无法继续的问题。
- 未配置本地模型时，默认模型查询交由 Cursor 官方服务处理。

## 发布调整

- 补齐 Linux ARM64 打包所需的系统依赖。v1.0.1 因该构建问题未完成发布，本版本包含全部修复。
