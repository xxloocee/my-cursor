# My Cursor v1.0.3

## 修复

- 修复等待 Cursor 请求上下文时取消无效、准备完成后仍可能调用模型的问题。
- 修复快速替换请求后上下文加载状态遗留的问题，并隔离旧请求的迟到响应，避免干扰新请求。
- 修复消息流重连时，旧连接断开可能取消新连接的问题。
- 修复官方模型消息流异常结束后丢失转发路由的问题；增加重连保留期限和路由等待超时，避免请求无限等待。
- 修复协议提取器将新版 Cursor 中的 `1e3` 字段编号误读为 `1` 的问题，完整校验数字字面量及 protobuf 字段编号，保留严格校验。
- 修复聚合搜索中重复网址被误算为多个搜索引擎共同命中的问题。

## 新增与调整

- 同步上游代码，新增供本地应用调用的外部模型 API 及相关设置。
- 增加可配置的 token 价格和巴西葡萄牙语界面，更新 Antigravity 模型支持。
- 桌面主窗口改为按需创建，并采用 mimalloc 改善内存管理；存储统计改为显示记录行数。
- 保留本项目去广告处理及已有模型配置、账号透传等修复。

## 验证范围

消息转发相关 Rust 测试 220 项、协议提取器 Go 测试、前端类型检查和生产构建均已通过，并完成独立代码审查。此前的 Windows x64 本地修复构建通过 release 编译及程序入口加载检查。

本次发布在上述修复基础上更新版本号及发布说明，由 CI 构建各平台安装包。本轮未重新进行真实 Cursor 故障注入或付费模型转发测试；macOS、Linux 及 ARM64 的本版本产物以 CI 构建结果为准，未宣称完成六平台实机验证。
